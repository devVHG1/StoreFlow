# Демонстрація StoreFlow

## Підготовка

Запустіть API за README. Для локальної PostgreSQL відкрийте http://localhost:5276, для Docker — http://localhost:8080.
Перед додаванням демонстраційних даних створіть копію бази. Виконайте scripts/Seed-DemoCatalog.ps1, для контейнера додайте -Docker.
Використовуйте окремі демонстраційні акаунти покупця та менеджера. Не показуйте паролі й JWT у записі демонстрації.

## Показ за 5–7 хвилин

1. Покажіть 12 товарів, категорії, пошук за назвою та сортування за ціною. Відкрийте опис товару.
2. Увійдіть покупцем, додайте товар у кошик і створіть замовлення. Покажіть суму та історію статусів.
3. У панелі менеджера відкрийте це замовлення, переведіть у Processing, покажіть фільтр статусу.
4. Скасуйте дозволене замовлення й перевірте повернення залишку. Історія має зберегти зміни.
5. У Swagger покажіть відхилення ціни 0 та відсутність доступу без авторизації. У GitHub відкрийте результат CI.
6. Коротко поясніть шари Domain, Application, Infrastructure та Api і зафіксовані обмеження з docs/RELEASE.md.
