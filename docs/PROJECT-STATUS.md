## Як продовжити завтра

1. Запустіть Docker Desktop і дочекайтеся готовності.
2. Відкрийте термінал у `D:\Project\StoreFlow`.
3. Виконайте `docker compose up -d`.
4. Виконайте `pwsh -NoProfile -File scripts/Test-DockerStack.ps1`.
5. Відкрийте [Swagger](http://localhost:8080/swagger).

Після змін коду використовуйте `docker compose up --build -d`.
Docker використовує окрему базу, тому користувачі та товари з запуску через Visual Studio автоматично в ньому не з’являються.
Для першого адміністратора Docker виконайте інструкцію з README. Нові реєстрації через API отримують роль Customer.

Зупинити проєкт зі збереженням даних: `docker compose down`.
Переглянути стан: `docker compose ps -a`.
Переглянути останні повідомлення API: `docker compose logs --tail 100 api`.
Не видаляйте том PostgreSQL, якщо потрібно зберегти дані.

## Що ще потребує роботи

- Перевірений сценарій резервного копіювання та відновлення PostgreSQL.
- Підтвердження email і відновлення пароля.
- Refresh-токени та керування окремими сесіями, якщо потрібен тривалий вхід.
- Навантажувальна перевірка та зовнішнє розгортання з HTTPS.
- Оплата й доставка, якщо вони входять до майбутнього обсягу проєкту.

Секрети залишаються локально в User Secrets і виключеному з Git `.env`.
Поточна Docker-конфігурація призначена для роботи на власному комп’ютері.

Додаткова перевірка 28.10.2026: EF Core оновлено до 8.0.33, Npgsql EF Core — до 8.0.11. Повторний аудит NuGet усіх прямих і транзитивних залежностей не виявив відомих вразливостей. Аудит додано до CI.
